# Thay icon ẩn trong file dịch bằng @lucide/vue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xoá 28 emoji/mũi tên đang đóng vai trò icon chức năng nhưng bị nhét trong giá trị chuỗi dịch (`i18n/locales/*.js`, 5 ngôn ngữ) và thêm icon `@lucide/vue` thật tại đúng vị trí render trong template — theo spec `docs/superpowers/specs/2026-08-07-thay-icon-i18n-design.md`.

**Architecture:** Với mỗi trong 9 file `.vue` bị ảnh hưởng: import icon component từ `@lucide/vue`, chèn `<IconName :size="N" style="vertical-align:-2px;" />` ngay trước (hoặc sau, xem từng task) `{{ t('key') }}`. Với mỗi trong 5 file dịch: xoá icon ký tự + 1 khoảng trắng theo sau khỏi đầu giá trị chuỗi, giữ nguyên phần chữ còn lại.

**Tech Stack:** Vue 3 (`<script setup>`), `@lucide/vue` (đã cài từ plan trước), Vite, Vitest.

## Global Constraints

- Chỉ đổi đúng 28 cặp (key, file dịch) liệt kê trong spec — không đụng emoji nào khác trong file dịch (kể cả emoji khác trong cùng file).
- Icon color: mặc định `currentColor` — không set màu cứng.
- Icon dùng `style="vertical-align:-2px;"` khi đứng cạnh text trong cùng dòng (đúng quy ước đã dùng trong plan icon trước).
- Không tạo wrapper component cho icon.
- Không đổi cấu trúc/copy bản dịch ngoài việc xoá icon ký tự đầu chuỗi + 1 khoảng trắng.
- Vị trí icon theo đúng hướng mũi tên gốc: `←`/`‹` (lùi/back) → icon đứng **trước** text; `→` (tiến/continue) → icon đứng **sau** text; icon không có hướng (✓, 🚚, 🎁...) → icon đứng **trước** text.

## Golden Reconstruct Procedure (bắt buộc dùng cho file "dirty")

**Khi nào cần:** một số file mục tiêu đang có thay đổi thật của người dùng CHƯA commit (tính năng dở dang, không liên quan đến task này). Task nào đụng các file này sẽ được đánh dấu **[DIRTY]** — với các file đó, dùng đúng quy trình 5 bước sau để commit chỉ đúng phần icon, không cuốn theo phần dở dang của người dùng. Task không đánh dấu DIRTY thì dùng Standard Task Recipe bình thường (Edit tool + `git add` + commit).

1. **Sửa file thật:** dùng Edit tool áp old_string → new_string trực tiếp lên file đang có trên đĩa (file dirty vẫn chứa nguyên các dòng target — đã xác minh diff dirty không đụng các dòng này). App/dev server vẫn chạy đúng ngay sau bước này.
2. **Dựng bản sạch:** `git show HEAD:<path> > <path>.clean.tmp`
3. **Áp lại đúng edit đó** (cùng old_string → new_string) lên `<path>.clean.tmp` bằng Bash (`python3 -c` hoặc `sed`, KHÔNG dùng PowerShell/`Out-File`/`Set-Content` — tránh BOM, xem bài học ở plan icon trước).
4. **Stage đúng blob sạch đó** (không phải file thật đang dirty):
   ```bash
   BLOB=$(git hash-object -w "<path>.clean.tmp")
   git update-index --cacheinfo 100644,$BLOB,"<path>"
   rm "<path>.clean.tmp"
   ```
5. **Verify trước khi commit:** `git diff --staged -- <path>` phải CHỈ hiện đúng edit của task này (không có dòng nào khác của người dùng lẫn vào). Nếu sạch, `git commit`. Sau commit, `git diff HEAD -- <path>` phải chỉ còn lại đúng các thay đổi dở dang gốc của người dùng (không mất, không lẫn icon).

## Standard Task Recipe (file không dirty)

1. Với mỗi icon mới, thêm vào dòng `import { ... } from '@lucide/vue';` trong `<script setup>` (gộp vào import hiện có nếu đã có).
2. Áp Edit (old_string → new_string) cho từng dòng liệt kê.
3. Với 5 file dịch của task: áp Edit tương ứng (xem bảng "Sửa file dịch" của từng task).
4. `npm run build` trong `FrontEnd/QLBanMayTinh` — bắt lỗi import sai tên/thiếu export.
5. Commit: `git add <đúng file(s) của task>` rồi `git commit -m "refactor(i18n): thay icon ẩn trong bản dịch ở <tên file>"`.
