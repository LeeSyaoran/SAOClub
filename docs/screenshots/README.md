# Hướng dẫn chụp ảnh màn hình

## Cách chụp ảnh

1. Mở trình duyệt Chrome/Edge
2. Truy cập: http://localhost:5173
3. Đăng nhập với tài khoản test
4. Chụp ảnh từng màn hình theo danh sách bên dưới
5. Lưu vào thư mục này với tên tương ứng
